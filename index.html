SPK Penentu Pakan Kucing Tua

Aplikasi berbasis web yang merekomendasikan jenis pakan terbaik untuk kucing senior berdasarkan kondisi kesehatan, usia, dan nutrisi khusus yang dibutuhkan.

Fitur Utama:

  • Perhitungan kriteria nutrisi & kondisi kesehatan otomatis
  • Peringkat pakan terbaik berdasarkan pembobotan
  • Manajemen data pakan dan kriteria oleh admin

Teknologi:

JavaScript Tailwind CSS MySQL PHP

Deteksi Gangguan Belajar Anak

Sistem pakar cerdas yang dirancang untuk membantu mengidentifikasi indikasi awal gangguan belajar pada anak (seperti disleksia, diskalkulia, atau ADHD) berdasarkan gejala yang diamati.

Fitur Utama:

  • Kuesioner diagnosis interaktif berbasis indikator perilaku
  • Kalkulasi tingkat kepastian/probabilitas hasil diagnosis
  • Laporan hasil analisa beserta saran atau rekomendasi penanganan awal

Teknologi:

JavaScript Tailwind CSS PHP MySQL

SPK Kelayakan Bantuan Posyandu

Aplikasi SPK mengimplementasikan metode SAW (Simple Additive Weighting) untuk menentukan kelayakan dan prioritas penerima bantuan operasional atau insentif Posyandu secara obyektif.

  • Perhitungan matriks keputusan & normalisasi SAW
  • Pemeringkatan otomatis penerima kelayakan bantuan
  • Cetak laporan dan ekspor hasil analisis

Teknologi:

JavaScript Tailwind CSS MySQL PHP
